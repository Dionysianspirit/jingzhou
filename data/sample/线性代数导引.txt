线性代数导引

第一章 向量与线性空间

向量是既有大小又有方向的量。在平面直角坐标系中，一个二维向量可以写成 v = (x, y)。向量加法按分量进行：u + v = (u1 + v1, u2 + v2)。数乘则把每个分量同乘一个标量：k v = (k x, k y)。

零向量 0 满足 v + 0 = v。向量 −v 称为 v 的负向量，满足 v + (−v) = 0。

一组向量 v1, v2, …, vk 的线性组合是任意形如 a1 v1 + a2 v2 + … + ak vk 的表达式，其中 ai 为标量。如果存在不全为零的系数使得线性组合等于零向量，则称这组向量线性相关；否则称为线性无关。

线性空间（向量空间）是对加法和数乘封闭、并满足八条公理的集合。最常见的例子是 R^n：全体 n 元实数组。子空间是自身也构成线性空间的非空子集，必须包含零向量，并对加法和数乘封闭。

一组向量的张成空间 span{v1, …, vk} 是它们所有线性组合构成的集合，它一定是子空间。

第二章 基、维数与坐标

如果一组向量线性无关，并且能够张成整个空间，就称它为该空间的一组基。同一个空间的任意两组基所含向量个数相同，这个个数叫做维数，记作 dim V。

R^n 的标准基是 e1 = (1,0,…,0), …, en = (0,…,0,1)。任意向量 x 在标准基下的坐标就是它自己的分量。

换基时，新旧坐标之间由过渡矩阵 P 联系：x_old = P x_new。P 的列是新基向量在旧基下的坐标。可逆性保证换基是一一对应。

第三章 矩阵与线性映射

m × n 矩阵可以看成从 R^n 到 R^m 的线性映射：T(x) = A x。矩阵乘法对应映射的复合： (AB)x = A(Bx)。单位矩阵 I 对应恒等映射。

矩阵的秩 rank(A) 等于其列空间的维数，也等于行空间的维数。秩-零化度定理：rank(A) + dim ker(A) = n，其中 ker(A) = {x | A x = 0} 称为零空间。

初等行变换不改变行空间，因而也不改变秩。把矩阵化成行阶梯形后，主元的个数就是秩。

第四章 线性方程组

方程组 A x = b 有解，当且仅当 b 落在 A 的列空间里，也就是 rank(A) = rank([A|b])。解若存在，通解等于一个特解加上齐次方程 A x = 0 的通解。

齐次方程永远有零解。非零解存在的充要条件是 rank(A) < n，即列向量线性相关。

高斯消元把增广矩阵化为行阶梯形，再回代求出自由未知量对应的参数解。这是求解中等规模稠密方程组最稳定的基础算法之一。

第五章 行列式与可逆性

只有方阵才有行列式。行列式 det(A) 可以按任一行（列）展开。三行三列的计算公式为：

det = a11(a22 a33 − a23 a32) − a12(a21 a33 − a23 a31) + a13(a21 a32 − a22 a31)。

det(A) ≠ 0 当且仅当 A 可逆，当且仅当 A 的列向量构成一组基，当且仅当 A x = 0 只有零解，当且仅当 rank(A) = n。这五条等价刻画是线性代数最常考的一条主线。

可逆矩阵的逆可以用伴随矩阵写出：A^{-1} = (1/det A) adj(A)。实际计算更常用高斯-若尔当消元，把 [A|I] 化为 [I|A^{-1}]。

第六章 特征值与对角化

如果存在非零向量 v 和标量 λ 满足 A v = λ v，则 λ 称为特征值，v 称为属于 λ 的特征向量。特征多项式是 p(λ) = det(A − λ I)，特征值就是它的根。

不同特征值对应的特征向量线性无关。如果 n 阶矩阵有 n 个线性无关的特征向量，就可以写成 A = P D P^{-1}，其中 D 是对角矩阵，对角元为特征值。这称为对角化。

对角化的用处是把矩阵幂化成标量幂：A^k = P D^k P^{-1}。在微分方程、马尔可夫链和主成分分析里都会用到。

并非所有矩阵都能对角化。若特征多项式有重根且几何重数小于代数重数，就只能化成若尔当形。本导引只要求掌握“可对角化 ⇔ 存在由特征向量组成的基”。

第七章 内积、正交与最小二乘

欧氏空间中的标准内积是 ⟨u, v⟩ = u1 v1 + … + un vn。正交是指内积为零。一组两两正交的非零向量一定线性无关。

格拉姆-施密特过程把任意基变成正交基，再单位化就得到标准正交基。正交矩阵满足 Q^T Q = I，它保持长度和角度。

当 A x = b 无解时，可以求使 ||A x − b|| 最小的 x，这就是最小二乘。法方程 A^T A x = A^T b 的解就是最小二乘解。若 A 列满秩，则 A^T A 可逆，解唯一。

附录 学习时常见的四个易错点

概念混淆：把“线性相关”说成“有一个向量是零向量”。零向量确实使整组相关，但相关的本质是“存在非平凡线性组合等于零”。

公式遗忘：忘记 rank(A) + dim ker(A) = n，在判断齐次方程非零解时漏看列数。

审题偏移：问的是列空间，答成了行空间；问的是是否可逆，却只计算了一个特征值。

推导断裂：由 A v = λ v 推出 det(A) = λ，漏掉了只有在一维时才可能成立。正确路线是把等式写成 (A − λ I) v = 0，再要求行列式为零。
